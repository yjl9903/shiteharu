## 工具

| 工具 | 功能与用途 |
| --- | --- |
| [yt-dlp](https://github.com/yt-dlp/yt-dlp) | 命令行音视频下载工具，用于下载 YouTube 等平台的原片，也可保存视频信息及平台提供的字幕。 |
| [rajio](https://github.com/yjl9903/rajio) | 面向 AI agent 的日语音视频字幕工作流工具，用于提取音频、日语转写与校对、简体中文翻译与润色，并导出日文／中文 SRT 和双语 ASS 字幕。 |
| [Forge](tools/forge/README.md) | 构建 ASS/SRT 字幕、准备字体与演出效果、渲染视频、生成截图和片段对照，并打包交付工程。 |
| [Loupe](tools/loupe/README.md) | 在浏览器中对照原片与成片，搜索字幕、检查字体覆盖，并自动同步工程更新。 |

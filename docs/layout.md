# 目录与模块职责

新增文件、调整目录或确定模块归属时参考本文。全仓库通用规则见 [AGENTS.md](../AGENTS.md)。

以下路径相对仓库根目录。按实际需要建立目录，不要求新工程预建空目录。

| 路径 | 职责 |
| --- | --- |
| `AGENTS.md` | 全仓库通用规则与按任务查阅的资料索引。 |
| `docs/` | 跨工程的资源、重建、交付和目录职责说明；单片细节仍留在对应工程。 |
| `README.md` | shiteharu 资料、视频索引、整体制作状态和工程入口。单片操作细节放到工程 README。 |
| `production/<工程>/` | 单个视频的独立制作工程；当前包含 `shingouki`、`ginzawa`。保存该片的内容、配置、专用脚本和交付结果。 |
| `downloads/` | 原片及下载素材，通常不入库；来源和校验信息保存在对应工程中，不修改原片。 |
| `fonts/` | 正式使用的共享字体、许可、来源及派生字形记录；来源索引为 `fonts/SOURCES.md`。 |
| `fonts/local/` | 不随仓库分发的本机字体副本；必须有准备说明，不作为隐藏依赖。 |
| `tools/<工具>/` | 跨工程使用的制作辅助工具，各自维护实现、依赖、说明与测试。 |
| `tools/loupe/` | 公共字幕与字体审阅工具，负责播放器、搜索、画面对照、同步、媒体探测和字体覆盖检查；通过工程配置读取输入，不导入单片 Python 模块。 |
| `scripts/` | 仓库级维护与检查，例如 `check_paths.py`；不放单片制作逻辑，也不复制公共工具实现。 |
| `.cache/` | 仓库级可重建缓存；Loupe 快照放在 `.cache/loupe/`。不保存唯一的人工成果，不纳入交付。 |
| `.env`、`.venv/` 等被忽略的环境文件或目录 | 本地凭据与运行环境；准备方法由相应文档和依赖清单描述。 |

以下路径相对 `production/<工程>/`。

| 路径 | 职责 |
| --- | --- |
| `README.md` | 原片来源、制作状态、编辑入口、依赖准备、重建命令和交付说明。 |
| `description.md` | 该片的语境、术语、翻译原则与内容决策。 |
| `session.toml`、`source.info.json` | 制作会话、原片标识与媒体元数据；按工程实际使用维护。 |
| `preview.toml`、`bilipack.toml` | 审阅工具或交付工具的工程配置；不承载工具实现。 |
| `transcript/raw/` | 原始转写与检查点，保留为参考依据，不直接改写为人工终稿。 |
| `transcript/work/` | 日文人工校对及时间轴工作数据。 |
| `translation/work/` | 中文翻译与润色工作数据；与设计数据共同构成字幕构建输入。 |
| `patches/` | 转写、翻译修订及其依据；候选建议须与已应用修改区分。 |
| `design/` | 字体角色、默认样式、逐条演出、补充字幕、对照片段及工程审阅内容；格式说明放在 `SCHEMA.md`。 |
| `scripts/run.py` | 工程制作命令入口，负责参数校验与分派。 |
| `scripts/pipeline/paths.py` | 工程定位和配置路径解析。 |
| `scripts/pipeline/subtitles/` | 字幕构建、排版、阴影和字形位置校准等单片演出逻辑。 |
| `scripts/pipeline/fonts/` | 字体准备、渲染缓存及已审阅字体方案的应用。 |
| `scripts/pipeline/research/` | 本工程的字体识别、派生字库和试排等研究脚本。 |
| `scripts/pipeline/delivery/` | 视频渲染、片段与截图对照、交付打包。 |
| `scripts/tests/`、`scripts/requirements*.txt` | 工程脚本的必要验证与依赖；新增制作命令按职责归类并接入统一入口。 |
| `research/` | 该片的研究依据、候选资源、实验数据与提案；获采纳的结果须明确应用到正式配置或资源，日常构建不隐式依赖实验缓存。 |
| `clips/`、`audio/`、`frames/` | 片段校对材料、提取音频与取帧证据；保留必要的片段配置和文字结果，媒体派生文件按规则忽略并可重建。 |
| `output/` | rajio 的标准字幕导出，不作为最终演出数据的手工编辑入口。 |
| `deliverables/` | 最终 ASS/SRT、预览、成片、对照与交付包；修改回到工作数据或设计源后重新生成。 |
| `.cache/` | 本工程的渲染字体缓存、日志等运行产物，区别于仓库级共享工具缓存。 |

公共工具负责通用操作，工程负责内容与制作决策。工程不复制 Loupe 的服务、播放器或兼容入口；Loupe 不生成单片字体提案、不自动修改译文，也不接管字幕演出构建。

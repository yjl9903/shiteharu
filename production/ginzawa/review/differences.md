# 制作范围与差异记录

已完成逐事件画面对照及成片采样复核。以下是交付版本仍然保留的差异，不宣称逐像素复刻。

- 视频原有日文已经烧录在画面中。中文另叠在日文附近或画面顶部，保留原字；因此中文的位置有意偏移，不是替换原画日文。
- 字体按原画的圆体、方黑、明朝、毛笔、细字和混合字形分别匹配。中文与日文笔画结构不同，所用中文字体是近似复刻，并非已确认原作者字体；精确差异写在每条设计的 `limitations` 中。
- 中文文本与原文长度不同，强调的宽高、行距和字幕块位置经过逐事件调整。原图标志不重复翻译；所有主字幕和登记的重要旁注另有中日文本。
- 长篇文章截图、现场招牌和环境细字保持原画；没有宣称翻译画面中的每一个文字像素。旁注、三条推文与正文词语梗另行翻译。
- 起止时间以源视频帧 PTS 为准。SRT 保留毫秒；ASS 采用向下取整到厘秒，适应该源片约33毫秒的帧间隔，不使文字延后一帧。并发旁注与动态演出以 ASS 为准。
- a088 原画为固定左缘连续擦出，字幕工具已支持连续动画裁切；中文字幕字形和宽度不同，擦出速度按整体持续时间匹配。
- 原片相邻帧边界校对、全部主字幕文字阅读、分段样式实看和完整媒体解码是不同的检查。采样联系表不等于逐帧观看完整影片或连续人工试听；最终检查范围见 `content-review.md` 和 `media-qa.json`。
- 本机字体只存放于被忽略的 `fonts/local/`，不随仓库分发。重新渲染须按字体表与仓库字体来源说明准备相同字体；已烧录成片不依赖播放端字体。

- 破损字新增 `GinzawaFractureSC`：保留源界明朝已有字形，对缺少的简体字以思源宋体 Heavy 加固定裂纹补齐。可见效果比纯宋体接近，字形来源仍不等于原作者字体鉴定，缺字补形与原画裂纹不完全相同。
- c065 原画为连续白遮条，中文审定文本中的三个方块渲染为三个独立白块；保持遮蔽和后缀含义，形状不是逐像素复制。
- a009 为保留放大推文及作者行，中文主句置于顶部单行并横向压缩；与原画底部双行的字形比例不同。滚动长句按中文实际墨迹宽度重算轨迹，擦出的中文波浪数量与原文 s 数量不同；旁注和片尾淡入淡出采用近似线性曲线。
- 可切换字幕的 MKV 未嵌入字体；播放 ASS 演出轨须准备字体表中的字库。1080p 与 720p 烧录视频不受此限制。纯 SRT 不保留字形、并发图层和动态演出。

# 字幕位置与字号专项复查（2026-10-18）

本轮按用户新授权整体检查位置与字号，采用「优先下方，再考虑上方；结合主体、表情、物件、标识、同屏文字及运动决定大字演出」的要求。此前明确指定的上/下位置继续优先。未重新导出整片或替换 Loupe 播放视频。

## 范围与证据

- 实际查看当前全部288个事件的中点合成截图，包括同屏字幕和旁注；索引为 `../frames/composition-review-01/index.json`，联系表24张。
- 对54条修改事件及6条保留的大字/滚动事件，查看10%、50%、90%三个时点，共180张图；索引为 `../frames/composition-review-02/index.json`。其中4条再细调后另看12张图，最终以 `../frames/composition-review-03/index.json` 为准。
- 本轮是静态及多时点构图检查，不是全片连续播放、逐帧运动验收、翻译复审或最终编码验收。中点图01有5次源H.264参考帧提示，图像均生成并实看；02和03未报告解码提示，不能据此代替全程解码检查。
- 完整文字和字体角色均保持不变；只改视觉排版、字号、描边及相应设计记录。a080仅将已有文字在演出轨排成一行，没有修改翻译文本。

## 结果

共修改54条，其中29条从上方回到下方，4条从下方改到上方，41条缩小字号；类别有交集。逐条修改前后参数、场景理由、证据和全部288条覆盖表见 [composition-decisions.json](composition-decisions.json)。

- 普通对白：b067–b068、b080–b081、c070–c074等，按实际眼口位置放回下方，不能因为保守人物框包含衣领就整段移顶。
- 包装和物件：b052–b053、b060等缩小放下，留出袋装商品的名称、增量标识和杯身。
- 中央特写：b029、b049、b064、b069、b084等保留顶部，但显著缩小，给表情让位；不复制原片巨字的占画面比例。
- 食品名称：c036、c059、c061、c062缩小放上，保留红薯旋转时的尖端、栗子银团切面、银锷饼馅料和牛蒡菜品。
- c067：玩偶银衣占下方中央、包装品牌在上方中央，短横排「闪闪发亮」放在下方左侧空地；不为了居中覆盖任一主体。
- a035保留空镜中的巨大「阴天」，a020保留城市名揭示的大字，避免把所有演出都机械缩成普通字幕。
- b046曾因缩略图怀疑下方靠近嘴部，放大并核对三个时点后确认眼口仍有空隙，因此保留缩小后的下方方案。a080另上移26px，解决与日文第一行描边过近的问题。

最终298个墨迹采样没有与记录的原日文字框相交，也没有非预期触边。人物框仍产生38个候选，框内包括头发、下巴、衣领和身体；逐条合成画面用于判断，未通过删除人物框或统一允许遮脸来消除告警。源字框本身是近似筛查工具，视觉检查结果优先。测量见 [layout-composition-final.json](layout-composition-final.json)。

## 重建本轮截图

最终编辑稿已在独立 `.cache/composition-final/` 完成288事件的ASS/SRT构建验证，没有覆盖交付目录。技术检查无缺字、缺失证据、缺失设计描述或机器绝对路径；详见 [composition-technical.json](composition-technical.json)。原有时序确认标记保持不变，本轮没有重新认证字幕边界。54条修改均有三个最终关键帧引用，288条覆盖记录与最终输入哈希已核对。

读取 `forge.toml`、当前编辑时间轴和设计，使用 Forge 的 `header`、`render_event`、`render_with_shadow` 构建完整ASS至独立 `.cache/` 目录，避免覆盖现有交付物。按照各阶段 `index.json` 的 `requested_time`，从配置指向的原片提取一帧；FFmpeg使用 `setpts=PTS+时间/TB,ass=相对ASS路径:fontsdir=.cache/render-fonts,scale=960:540`。全部并发事件一起渲染，勿仅渲染被检查的单条。索引记录所用ASS的SHA256；最终设计输入哈希在决策文件。01和02为本轮中间证据，最后4条以03为准。

无需原机器绝对路径；先按工程README准备原片与字体。原片、字库和编辑稿是重建输入，截图缓存不是唯一数据源。
